Ejemplo del capítulo 05 · El mes en que empezó a ser costumbre. Un mes bloqueado usa la misma cabecera pero con el candado a la derecha y un texto distinto (ver month-locked.html).

Para el port a React

Componente
MonthMasthead
Clases raíz
.masthead → .masthead__num + .masthead__copy
Wrapper
Vive dentro de <article class="month">, seguido de .month__rule, que lo separa de la carta
Número
padStart(2, "0") y .od-nowrap para que “05” no se parta
Fecha y lugar
{dateLabel} y {place} unidos por .masthead__sep (punto medio decorativo, aria-hidden); si no hay lugar, no se pinta el separador
Accesibilidad
El id="card-title" es el que etiqueta la sección de la vista de mes, así que el nombre no puede cambiarse al portar
